## Limitations
- 26 hand-written cases; pattern checks are easy to paraphrase around (see the false negative). This is not evidence of comprehensive prompt-injection prevention.
- The mock provider is deliberately fully injectable; real models differ.
- The gateway's safety rests on deterministic controls that do not depend on detection: write tools need capability + policy + request type + untainted context, every proposal needs independent human approval, and no tool executes system changes.
