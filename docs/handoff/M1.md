# Handoff — M0 + M1 (2026-11-22)

## Result

The M1 vertical slice works end to end on native PostgreSQL 16: an analyst signs in, imports
the synthetic fixture through the normal ingest path, the worker produces one alert and one
incident, and the dashboard shows the incident, its evidence timeline and each underlying event.

## Decisions taken without the maintainer (all reversible)

  if preferred.
- Sync FastAPI + SQLAlchemy instead of async: simpler, sufficient for M1 volumes.

## Next: M2 (lightweight agent, Go)

Per-agent enrollment tokens and a producer identity per agent; a Linux auth-log collector
(`/var/log/auth.log` / journald) mapping to the v1 contract with stable `native_id`
(inode + offset or journald cursor); local disk buffer with bounded size and replay; batching,
backoff, clock-skew reporting; a heartbeat endpoint and an "agents" view. The ingest API and
dedup key already support this without changes.
